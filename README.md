# FAQ Service — сервис организации вопросов и ответов

## Назначение

Приложение представляет собой веб-сервис организации FAQ, в котором
пользователи могут задавать вопросы в тематических разделах,
отвечать на вопросы других пользователей, а администратор —
модерировать вопросы и закрывать обсуждения.

## Целевая аудитория

- обычные пользователи, ищущие ответы на типовые вопросы;
- пользователи-эксперты, отвечающие на вопросы;
- администраторы, управляющие разделами и модерирующие контент.

## Предметная область

Организация базы знаний в формате «вопрос — ответ» по тематическим
разделам. Каждый вопрос относится к определённому разделу, имеет
автора, статус и может быть закрыт модератором после получения ответа.

## Основные сущности

- `Section` — тематический раздел, хранит название и признак активности;
- `User` — автор вопроса или ответа, хранит имя пользователя;
- `Question` — вопрос в разделе, хранит автора, дату, статус и список ответов;
- `Answer` — ответ на вопрос, хранит автора, текст и дату.

Все четыре модели явно реализуют `__init__()` и `__str__()`. Метод
`Question.add_answer()` добавляет ответ только к открытому вопросу,
`Question.close()` закрывает обсуждение. `Question` и `Answer` хранят авторов
как объекты `User`; строковое представление моделей используется в консоли.
Функции `questions.py` отвечают за проверки прав и операции над коллекцией
вопросов, а `storage.py` преобразует объекты в JSON и обратно. В JSON авторы
остаются строками, поэтому существующий файл данных сохраняет совместимость.

## Роли и права

| Действие                          | Гость | Пользователь | Админ |
|-----------------------------------|:-----:|:------------:|:-----:|
| Просмотр вопросов и ответов       |  да   |     да       |  да   |
| Создание вопроса                  |  нет  |     да       |  да   |
| Ответ на вопрос                   |  нет  |     да       |  да   |
| Модерация и закрытие обсуждения   |  нет  |     нет      |  да   |

## Основные функции

- просмотр вопросов и ответов (доступен всем ролям);
- создание вопроса пользователем в выбранном разделе;
- добавление ответа на существующий вопрос;
- проверка прав роли на выполнение действия;
- модерация вопроса администратором (закрытие обсуждения).

## Веб-интерфейс

Веб-часть Django содержит пять основных страниц: главную, список вопросов,
каталог разделов с вопросами выбранного раздела, форму создания вопроса и
страницу отдельного вопроса. Также есть собственная страница 404. HTML
формируется Django Template Language: страницы наследуют `templates/base.html`,
переопределяют блоки `title` и `content`, а общая навигация и статус вопроса
подключаются через `{% include %}`. Представления передают данные в шаблоны
через контекст; списки и ответы выводятся циклами, пустые коллекции и состояния
вопросов обрабатываются условиями. Для ссылок используются именованные URL
пространств `homepage` и `faq`; в шаблонах применяются фильтры `length`, `date`
и `default`.

Общий базовый шаблон подключает собственные CSS и JavaScript, а также локальный
SVG-логотип из `static/`. JavaScript подставляет текущий год в подвал.
Представления используют `render()`; HTML в Python через `page()` не
формируется.

Данные веб-интерфейса по-прежнему хранятся в `data/faq.json` и обрабатываются
существующими классами предметной области и функциями сервиса. Django ORM для
предметных данных не используется; база данных Django не является хранилищем
вопросов. Формы создания вопросов и ответов уже доступны в веб-интерфейсе;
учётные записи, вход и полноценное управление ролями через веб пока не
реализованы.

## Запуск веб-приложения

Требуется Python 3.10 или новее. Установите Django и запустите сервер из
каталога проекта:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Веб-интерфейс содержит главную страницу,
список вопросов (`/faq/`), форму создания (`/faq/new/`) и страницы вопросов
(`/faq/<id>/`), а также каталог тематических разделов (`/faq/sections/`).
Выберите раздел, чтобы увидеть его вопросы. Данные загружаются из
`data/faq.json`, поэтому консольный проект ПР3 и его формат данных сохранены.
На странице списка можно задать вопрос, а на странице открытого вопроса —
добавить ответ. В формах указывается имя автора; регистрация и вход пока не
реализованы. Закрывать обсуждения можно через консольное приложение под ролью
`admin`.

Для возврата к консольному приложению запустите `python main.py`. При первом
запуске оно загружает начальный сценарий из `data/faq.json`. Пользователь
может создавать вопросы и ответы, искать и сортировать вопросы; закрывать
обсуждения может только роль `admin`. Изменения сохраняются в JSON после
каждой операции и при выходе.

## Структура программы

- `main.py` — консольное меню и обработка пользовательского ввода;
- `manage.py`, `faq_service/` — запуск и настройки Django-проекта;
- `homepage/`, `faq_web/` — приложения главной страницы и FAQ;
- `templates/` — базовый шаблон, навигация и шаблоны пяти основных страниц FAQ;
- `static/` — собственные CSS, JavaScript и SVG-логотип веб-интерфейса;
- `models.py` — классы `Section`, `User`, `Question` и `Answer`;
- `questions.py` — проверка прав, создание, поиск, сортировка и закрытие;
- `storage.py` — чтение и запись JSON с обработкой файловых ошибок;
- `utils.py` — интроспекция функций сервиса;
- `data/faq.json` — начальные и сохраняемые данные;
- `tests/` — тесты предметной области, JSON-хранилища и веб-страниц.
